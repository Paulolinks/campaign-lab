# Kit de implementação — CS Campaign Lab

Este ZIP é um **brief completo para o Claude construir o aplicativo**; não é uma versão de produção. O protótipo HTML abre offline e usa valores estritamente fictícios para demonstrar a interface.

## Arquivos

1. `01_ESPECIFICACAO_PARA_CLAUDE.md` — produto, fluxos, entidades, integrações, métricas, segurança, endpoints e fases.
2. `02_EXEMPLO_CAMPANHA_IMPORTAVEL.txt` — **3 anúncios de mini-split** com ângulos distintos, em formato CSCAMP/1.
3. `03_PROMPT_INICIAL_CLAUDE.md` — instrução a colar no Claude dentro do VS Code.
4. `04_PARSER_REFERENCIA.ts` — parser TypeScript base para o TXT, com validações.
5. `05_PROTOTIPO_VISUAL.html` — dashboard de demonstração **sem APIs reais**; abra no navegador e navegue pelas abas.
6. `Guia_Persona_Cool_Season_para_IA.md` — persona mestra em texto, já produzida no projeto.
7. `Persona_Mestra_Cool_Season_HVAC_2026.pdf` — persona mestra em PDF.

## O que fazer agora

1. Extraia este kit numa pasta no seu repositório ou dentro do workspace em VS Code.
2. Abra `05_PROTOTIPO_VISUAL.html` no navegador para visualizar o conceito.
3. Cole `03_PROMPT_INICIAL_CLAUDE.md` no Claude, solicitando que leia os arquivos.
4. Peça para construir o MVP local **antes** das integrações externas.
5. Configure Google Drive e Meta nas etapas respectivas, com OAuth e credenciais reais.
6. Não lançar anúncio sem revisar informações reais do site, serviço, garantia e financiamento.

**Recomendação de produto:** Não usar Marketplace como âncora técnica. A base deve ser o catálogo de campanhas + métricas comerciais + Meta Ads read-only + website + Drive. Marketplace, se permitido, é registro manual.
